# Reports

Ce dossier contient des exemples de rapports générés par le script `Test-IvantiPorts.ps1`.

Les fichiers présents ici sont fictifs et anonymisés. Ils servent uniquement à illustrer le rendu CSV et HTML produit par le script.

## Fichiers

- `sample-client-port-report.csv` : exemple de rapport CSV pour un profil Client.
- `sample-client-port-report.html` : exemple de rapport HTML pour un profil Client.
- `sample-coreserver-port-report.csv` : exemple de rapport CSV pour un profil CoreServer.
- `sample-coreserver-port-report.html` : exemple de rapport HTML pour un profil CoreServer.
