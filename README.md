# PowerShell Admin Toolkit

Collection de scripts PowerShell destinés à faciliter l’administration Windows, le diagnostic système, le reporting et l’automatisation de tâches IT courantes.

## Objectif

Ce dépôt me permet de centraliser des scripts PowerShell utiles dans un contexte d’administration systèmes et postes de travail.

Les scripts publiés ici sont pensés pour être simples, lisibles, documentés et facilement adaptables à différents environnements Windows.

## Scripts disponibles

| Script | Description |
|---|---|
| Get-SystemReport.ps1 | Génère un rapport système de base |
| Check-DiskSpace.ps1 | Vérifie l’espace disque disponible |
| Get-InstalledSoftware.ps1 | Liste les logiciels installés |
| Check-WindowsServices.ps1 | Contrôle l’état de services Windows |
| Test-NetworkConnectivity.ps1 | Teste la connectivité réseau |

## Compétences mises en avant

- PowerShell
- Administration Windows
- Diagnostic système
- Automatisation IT
- Reporting
- Administration postes de travail
- Bonnes pratiques de scripting

## Prérequis

- Windows 10 / Windows 11 / Windows Server
- PowerShell 5.1 ou PowerShell 7+
- Droits administrateur selon les scripts utilisés
